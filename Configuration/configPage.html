Custom Logo

Replaces the Jellyfin logo in the web client header and on the loading splash screen. The image is embedded in the server's custom CSS, so it also appears on the sign-in screen.

Turn this off to restore the default Jellyfin branding without deleting the uploaded image.
PNG, SVG, WebP, JPEG or GIF. A wide transparent PNG around 400×60 px works best for the header. Keep it under 1 MB — the image is inlined into the stylesheet that every client downloads.

Current logo

A CSS length such as 13.2em, 200px or 15%. Defaults to 13.2em, which matches the stock Jellyfin banner.
Optional. Appended inside the block this plugin manages in Dashboard → General → Custom CSS. Anything you write there yourself is left untouched.
